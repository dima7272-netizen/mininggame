# Dig Get Stronger

Репозиторий игровых JSON-конфигов, Roblox-загрузчика и безопасного контура публикации.

В `tools/balance-console` добавлен русскоязычный веб-сервис управления балансом: точное редактирование больших чисел, связанные редакторы игровых сущностей, проверки, неизменяемые версии, роли, приглашения, DEV → тестирование → PROD и безопасный мок публикации.

- [Документация и локальный запуск](tools/balance-console/README.md)
- [Аудит источников, формул и рисков](tools/balance-console/AUDIT.md)

Внешние изменения не выполняются автоматически: текущая реализация публикации намеренно использует мок-адаптер.
